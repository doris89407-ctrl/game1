# 星星小鎮｜小小投資家任務

給小學生使用的一頁式生活理財與投資教育遊戲，包含可玩的投資模擬、教師教學建議、學習評量方式，以及學生自行設計遊戲的任務與提示詞鷹架。

## 在本機預覽

直接以瀏覽器開啟 `index.html` 即可。網站使用原生 HTML、CSS 與 JavaScript，無需安裝套件或建置。

## 發佈到 GitHub Pages

1. 將 `index.html` 和 `README.md` 推送到 GitHub repository 的根目錄。
2. 在 repository 開啟 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` 分支與 `/(root)` 資料夾，按 **Save**。
5. 等待 Pages 部署完成後，從 Pages 設定頁開啟網站網址。

## 教學設計

- 適用：國小社會課的股票與公司初探，也可延伸到數學資料整理、媒體素養與決策討論。
- 遊戲：探索四間店、閱讀事件、買入或保留星星、觀察模擬市場變化、回顧投資理由。
- 學生創作：訂學習目標、設計公司與事件、撰寫提示詞、試玩修正並以規準反思。

遊戲中的星星與價格皆為虛構教學模擬，不代表真實投資或報酬預測。
